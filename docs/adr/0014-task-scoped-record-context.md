# 项目记录按适用任务提供

2026-11-14，用户确认独立任务各自保留细节，协调者掌握摘要并明确转交跨任务资料。项目记录区分作者与适用范围。共同规则可共享，任务资料只提供给所属 Task，未声明范围的历史记录先供协调者查询。

记录查询、工具返回和自动上下文使用相同可见性规则。持续变化的资料在实际输入时提供，不拼入所有成员的稳定执行指令。继续复用原 Task、Thread、追加历史、请求回执与审批绑定，避免重新建立任务和第二套执行系统。

选择单目标任务范围与显式转交，保留项目级 CAS。相比多目标受众或关系图，任务资料的接收者可以直接核对。验证者只获得明确转交的验收要求、变更与证据。

2026-11-14，main 的 PR #28 和 ADR-0012 更新确定协调者只由明确事件唤醒，取代本分支早期的周期监督暂停方案。本分支尚未发布的 supervision action、项目监督状态和 superseded 状态直接删除。历史自动副本沿用 PR #28 的严格身份核对及 dropped 终态，已尝试的未知投递仍需对账。Task 暂停和原生审批身份保持原有合同。

记录范围不决定是否发起汇报。Worker 普通对话留在本任务，正式进展、阻塞与成果通过 report 提交。用户要求同步讨论时，Worker 汇报有真实来源的摘要；协调者再选择需要转交给其他任务的资料。
