# 项目记录按适用任务提供

2026-11-14，用户确认独立任务各自保留细节，协调者掌握摘要并明确转交跨任务资料。项目记录区分作者与适用范围。共同规则可共享，任务资料只提供给所属 Task，未声明范围的历史记录先供协调者查询。

记录查询、工具返回和自动上下文使用相同可见性规则。持续变化的资料在实际输入时提供，不拼入所有成员的稳定执行指令。继续复用原 Task、Thread、追加历史、请求回执与审批绑定，避免重新建立任务和第二套执行系统。

选择单目标任务范围与显式转交，保留项目级 CAS。相比多目标受众或关系图，任务资料的接收者可以直接核对。验证者只获得明确转交的验收要求、变更与证据。监督暂停单独持久化，不依赖项目记录的自然语言描述。
