# 工程入口支持共享项目目录

2026-11-06，用户明确选择整个 OpenTest 项目目录作为工程入口，其中包含框架、插件仓库和资料。仓库配置新增显式 workspace 策略，在默认的独立 Git worktree 之外，允许返回已存在的项目目录。沿用仓库身份与 ensure_workspace 入口，避免为这次目录选择增加第二套项目身份和别名关联；GitHub 采集条件保持原样。

项目目录由多个任务共享，是对 ADR 0003 独立工作目录约定的明确扩展。Runtime 只验证目录关联，不提供项目文件的任务间隔离；Agent 按项目说明使用子仓库与 worktree。获取目录不扩大原生文件权限。

已有任务继续使用保存的资源种类、路径和分支，新配置只影响首次申请的资源。共享目录保存规范路径，恢复时遇到目录丢失或符号链接改指向即报错，不重建、不改绑。历史没有资源种类的记录按原 Git worktree 事实解析。
