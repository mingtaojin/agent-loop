# 项目看板的首版边界

Status: accepted

项目看板首版采用项目总览和任务深钻两层只读视图。总览包含项目协调者、Worker、verifier、已路由 intake 以及已结束历史任务，只显示任务卡片和每个任务的最近活动，不建立跨 Worker 的项目总时间线。任务深钻显示 Codex CLI 风格的可见执行说明、任务生命周期、工具开始/结束元数据、错误和显式 report，并永久保留完整可见文字和报告历史；工具输出正文、隐藏模型推理和私有 textDelta 不进入看板持久化记录。看板监听网络地址，任何能连通端口的电脑都可以读取所有项目和任务数据，不要求登录、token 或项目级鉴权。

这样可以复用现有项目关系和任务执行事实，长期保留真正需要复盘的可见过程文字和报告，同时避免把高频工具输出写入数据库。
