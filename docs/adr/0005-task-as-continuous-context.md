# Task 表示一件事情的持续上下文

2026-11-05 已确认设计，尚未实现。Task 创建时可以只有讨论主题，不要求已有明确目标；同一 Task 从讨论发展为调查或实现，始终对应一个独立飞书群和持续的 Codex 会话，以免按工程阶段拆散上下文。

创建 Task 不再绑定创建仓库 worktree 或启动 Bug 修复；工程工作按用户意图和 Agent 判断推进，需要改代码时再准备工作目录。一项 Task 可以涉及多个仓库，使用哪些仓库及如何组织工作由 Agent 和工具处理，Runtime 不限定单仓库，也不规定 PR、push 或部署等交付方式。

本决策扩展 ADR 0001、0003，并取代旧版规格中 Task 创建即准备单仓库工程工作区的约束；旧版规格保留为实现历史。
