# 新需求只在项目协调群交办

2026-11-13，用户明确选择“移除 CLI 和私聊两个入口，只在项目群交办”。
多入口使用户和代理需要辨认请求、澄清与正式执行的归属，也扩大了 Runtime 的接单与恢复职责。
本决定取代 ADR 0011 中 CLI 和私聊可新建请求、补充回答的选择。

Runtime 移除外部 submit、answer 及其本机 HTTP 服务，忽略机器人私聊消息。
帮助和正式 Thread 指导不再提供这些命令。不提供继续接单的兼容开关。
所有者在项目协调群交办，协调者评估后通过内部 project_action 委派或补充指导。
运维 CLI 与内部 project-client、workspace 工具继续保留。

GitHub 收集仍保存来源证据并交给协调者决定，项目发现不会扩大收集仓库。
既有接单记录、Task、Thread、资源、暂停、失败、原生请求和审批回调继续保留。
旧 CLI 来源与消息类型仍可读取，status --request-id 可只读查询历史回执。
旧材料不因为入口移除而删除或复制成新任务。

本实现保留 PR17 db85f353 的项目责任、材料、去重、晋升和恢复机制。
默认无任务群及按需开群遵循 ADR 0012。进度总览不在本次决定中。
