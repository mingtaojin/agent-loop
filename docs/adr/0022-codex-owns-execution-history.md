# Codex 保存执行历史

2026-11-20，用户确认执行历史由 Codex 保存，Agent Loop 查看任务详情时读取当前 Thread，运行中的展示使用有界内存数据。此决策取代 ADR 0016 中由看板永久保存可见过程文字的约定，不迁移旧 Thread 或旧执行轨迹。

SQLite 继续保存任务、业务输入输出、显式汇报、审批和项目记录。飞书进度发布成功后只保留标识、摘要和发布状态。需要确认外部写入结果的正文仅作为待确认操作保存，确认后清除，不能归档为另一套执行历史。

历史读取不得恢复 Thread、启动 Turn 或处理原生请求。Codex 历史不可用时，看板明确显示读取失败并保留业务事实，飞书保留已发布内容等待重试。项目总览不逐个读取 Thread 历史。实时游标失效时，客户端重新读取当前历史。

历史快照与实时通知没有共同的增量偏移。没有收到消息起点时，增量只触发重新读取，不猜测文字重叠。未解决缺口的身份被内存上限淘汰后，运行中的历史保留重读提示，完整结束的历史可以恢复可用状态。此保守行为避免用缺字的轨迹冒充已同步结果。
