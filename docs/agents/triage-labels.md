# Triage Labels

| 角色 | 本项目取值 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格充分，可交给 agent |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不处理 |

本地 tracker 使用 Status: 行记录这些值。
它们不是应用运行时的 GitHub 收集条件。
