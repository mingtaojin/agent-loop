# 实现通用 CLI 新任务提交

## 目标

实现规格中的通用 CLI 提交入口。原 Agent 提供完整 prompt，常驻 Runtime 受理并创建独立任务，复用既有群、工程选择和正式会话流程。

## 范围

- 设计并实现 CLI 来源、提交请求与回执。
- 实现保持 Runtime 唯一写者的本机提交接口及生命周期。
- 增加文件和标准输入提交、机器可读回执与任务查询。
- 处理稳定请求身份、重复提交、内容冲突与未知回执。
- 更新所有来源消费者与正式 Agent 的 CLI 使用指导。
- 增加实际 CLI 到隔离 Runtime 的行为测试，保留旧来源回归。

## 验收

CLI 提交原文进入新任务首轮；原任务保持原身份；新任务具备独立群和正式 Thread；重试不重复新建；并发、重启与不可用服务得到可核对结果。静态检查、构建与回归测试通过，独立验证者操作实际 CLI 并记录证据。

## 约束

不要修改生产配置、重启生产服务或向真实飞书群发送消息。工作目录没有 Git 元数据，使用改前快照审查，不初始化仓库或创建远端工单。实现状态写入本工单 Comments，不增加未定义的分诊标签。
