# 按需读取 Codex 执行历史

Status: ready-for-agent

用户要求任务详情按需读取当前 Codex Thread，运行中接收实时消息。Agent Loop 不长期保存另一套执行轨迹，不处理旧 Thread 或旧历史兼容。

## 验收

- 新数据库没有 execution_events 表，运行中不向数据库或本地文件写入执行轨迹副本。
- 看板任务详情从 Codex 读取可见历史。读取不恢复 Thread、不启动轮次、不回答审批。
- 实时消息与历史按稳定消息身份合并，完成文字不重复。
- 实时游标在进程重启或缓存丢失后触发重新加载。
- Codex 不可用时仍能查看业务事实，飞书不以空历史覆盖现有内容。
- 飞书发布成功后，数据库只保存发布标识、摘要和状态，不保存已发布正文。待确认操作可保存准确的重试正文，确认后清除。
- 任务生命周期、业务输入输出、显式汇报、审批和项目记录继续持久保存。

## 范围

修改本地源码、测试和文档。生产实例重启、数据清理与旧历史迁移不在本次范围。
