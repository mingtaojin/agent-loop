# 07: 新消息继续已结束 Worker 的原会话

Status: ready-for-agent

规格：[Agent 协作工具简化](../spec.md)。用户故事：12、30、32、33、37、43。

**What to build:** 任务结束后，用户或协调者发来新消息，原 Worker 保留上下文继续处理，必要时重新准备资源。

**Blocked by:** [01 协调者与 Worker 双向消息闭环](01-agent-messaging.md)；[06 任务结束与资源清理独立执行](06-completion-cleanup-separation.md)。

- [x] 用户群消息和新的 Agent 消息均可继续原 Worker 与 Thread，不强制转给协调者另建任务。
- [x] 继续工作更新当前完成标记或状态，同时保留之前的完成摘要、记录、群和执行身份。
- [x] 只有暂停继续阻止自动执行；完成标记不再作为永久拒绝输入或工具调用的条件。
- [x] 清理进行中保存输入并等待资源状态确定，不启动与清理冲突的执行。
- [x] 文件已经清理时，原会话仍能收到消息和实际资源状态，Agent 能按需使用已有资源工具准备工作目录，不假定已删文件仍存在。
- [x] 更新续接相关入口、prompt、状态查询和看板行为，保留是否另建任务由协调者判断的选择。
- [x] 迁移旧完成记录后不会主动唤醒历史任务；只在实际新输入到达时按新契约处理。
- [x] 使用真实资源验证完成后追加、清理中追加、清理后追加、暂停及重启后续接。
