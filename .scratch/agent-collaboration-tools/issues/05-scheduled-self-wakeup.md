# 05: 可取消且可恢复的一次性自我唤醒

Status: ready-for-agent

规格：[Agent 协作工具简化](../spec.md)。用户故事：26、27、28、29、30。

**What to build:** 协调者和 Worker 可以安排一次未来提醒，到期后在原上下文继续处理等待事项。

**Blocked by:** None (can start immediately)。

- [ ] Agent 可以为自己创建、查询和取消带触发时间与内容的一次性提醒，不能替其他角色安排提醒。
- [ ] 到期提醒进入现有任务输入流程，运行中追加、空闲时开始一轮；未设置提醒时不产生周期监督。
- [ ] 提醒持久保存，重复扫描、重试和服务恢复不会重复触发同一提醒。
- [ ] 暂停期间到期的提醒被保存，不自动恢复任务，显式恢复后继续处理。
- [ ] 工具回执与状态查询区分未触发、已触发和已取消的实际结果，取消与到期并发有确定结果。
- [ ] 相关 prompt 指导 AI 根据需要安排回访和取消过期提醒，不固定要求每个任务设置相同时长。
- [ ] 在现有 Runtime 测试中控制时间，覆盖未到期、到期、取消、重启、暂停和无提醒的情况。
