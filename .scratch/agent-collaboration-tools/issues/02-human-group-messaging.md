# 02: 独立群消息工具与两类群体验

Status: ready-for-agent

规格：[Agent 协作工具简化](../spec.md)。用户故事：20、21、22、23、24。

**What to build:** 协调者通过独立工具选择发给用户的消息，Worker 群继续自动展示完整助手交流。

**Blocked by:** None (can start immediately)。

- [x] 向群发消息是独立工具，仅发送供人阅读的内容，不向其他 Agent 注入执行输入。
- [x] 协调者的普通最终答复不再按输入来源自动进入群；主动发送后群里可见，包括对用户直接提问的回答。
- [x] Worker 群保留完整助手过程说明、问题及最终回复的默认输出，普通回复无需额外调用发送工具。
- [x] 同一次主动群投递不会被旧公告入口或最终答复转发重复发送，重试与丢失回执沿用已有去重和对账能力。
- [x] 删除被替代的旧公告发送入口和分类要求，迁移相应调用方及动态提示。原生问题、审批、权限和系统异常渠道保持可用。
- [x] 使用已有协调者建群能力即可独立演示本切片；验证两个群的输出、投递记录与重启后的行为。
