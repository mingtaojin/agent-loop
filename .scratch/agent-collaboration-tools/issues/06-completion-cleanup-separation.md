# 06: 任务结束与资源清理独立执行

Status: ready-for-agent

规格：[Agent 协作工具简化](../spec.md)。用户故事：31、34、35、36。

**What to build:** 协调者结束任务时保留文件，需要释放空间时再单独调用清理工具并查询结果。

**Blocked by:** None (can start immediately)。

- [ ] 记录任务结束只保存当前结论与摘要，不创建或隐式推进一项新的清理操作。
- [ ] 独立清理工具可以处理明确指定、归属清楚的任务资源，包括已结束任务的资源，不能因已结束而无法清理。
- [ ] 任务当前完成情况和清理状态可分别查询，看板不再把两者呈现为同一结果。
- [ ] 保留资源身份、归属、占用与并发检查，原始资料、共享目录和其他任务资源不被误删。
- [ ] 清理与资源使用互斥，无法立即处理的清理返回真实状态；响应丢失或重启不会重复误删。
- [ ] 同步迁移该生命周期切片的数据、调用方和 prompt。旧完成记录保持可读，升级不凭完成标记生成新的删除请求。
- [ ] 使用现有真实文件、Git 工作树、子进程和 Runtime 集成测试验收；本切片暂不改变结束后的输入续接规则。
