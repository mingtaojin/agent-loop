# 本地任务调试台

Status: ready-for-agent

## 目标

开发时在一个网页查看所有任务、执行状态、模型流式文字、工具输出和原始执行错误。可追踪 Selected model is at capacity 等未进入飞书通知的事件。

## 实现范围

- 使用相同配置的独立 dashboard 命令，默认本机 HTTP，可通过 dashboard.host 显式监听全部 IPv4 接口，只读任务数据库。
- Codex 适配器将明确允许的文字、工具和生命周期事件投影为调试事件，原运行进程负责持久化，网页通过 SSE 续接。
- 列表按任务隔离，展示状态、会话、恢复、原生请求、消息和诊断。
- 模型最终消息替换同一 item 的片段，避免重复显示。
- 不修改任务调度、恢复、飞书通知或模型切换策略，不记录私有推理或原始协议配置。

## 验证

真实 HTTP、SQLite、受控协议子进程测试；浏览器验证逐段输出、任务切换、错误展示、刷新回放及移动布局。
